# Project knowledge Guide: durable knowledge goes in source control, not private memory

How to apply the Stance *durable knowledge goes in source control, not private memory*, from [the Project knowledge Guide](../project-knowledge.md#stance-durable-knowledge-goes-in-source-control-not-private-memory), which states the Stance and why.

- Update the docs instead of writing a memory file. A handoff document (the `handoff` Skill) is transient by design: before writing one, make sure anything durable is already in a commit, a doc or an issue.
