# Project knowledge Guide: there is no decision-record layer

How to apply the Stance *there is no decision-record layer*, from [the Project knowledge Guide](../project-knowledge.md#stance-there-is-no-decision-record-layer), which states the Stance.

## Why, in full

A decision record is a chronology; to understand today's design from it, a reader reconstructs a trail of superseded choices, and records drift from the design they describe. The chronology already exists in git and PR history (see the Agentic development Guide's *decide, record, carry on*).

## How to apply

- Wanting to write "we decided X over Y because Z" signals that the system-design doc under-explains the present: fold the reason, including why Y fails, into the doc. When the design changes, rewrite the doc to describe the new present.
