When a grill settles an experiment, it fixes the rule that will read the result before the result exists: what counts as the belief holding, and what counts as it failing. The rule in this grill named only those two, both written around the predicted direction: "holds" if a variant doesn't beat the baseline and changes few choices, "fails" if it beats the baseline significantly. The result fell outside both. The variant changed three times as many choices as the noise yardstick *and* lost significantly (sign z −2.00). The rule had no outcome for that, so the slice had to read it ad hoc, which is exactly what a rule set in advance is meant to prevent. The Skill could say that a reading rule set in a grill covers every combination of its measures, including a significant result in the opposite direction to the prediction, and says for each what it means for the belief. A two-by-three table (diagnostic small/large × strength worse/level/better) is a quick check that none is missing.
