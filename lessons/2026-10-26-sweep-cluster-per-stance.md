The Skill flags a Guide with five or more Lessons for a grill instead of Promotion. On its first run, the Web apps Guide had exactly five, but they were five separate small items (a route rule, an htmx version, a SQLite procedure, a timetable rule, a feed trap) and promoted cleanly. Model calls had 14, with four on one Stance. What signals a Guide still taking shape is several Lessons bearing on the **same Stance**, not the count per Guide. The flag should count per Stance (say, three or more), or look at whether the Lessons contradict the Guide rather than add to it.

Also from the first run: Startup should create one task per Guide in the plan, as `grind-issues` does per issue, so the owner can see where a long run is.
