When an Adopter's only user is also its builder, **the owner's own feedback, kept in the product's data and typed by kind, is a derived instrument** for the parts under the top hypothesis. In a domain the project defines itself (the owner's interests), it serves where no outside ground truth exists. Its known error is that less feedback looks like improvement, so those readings hold only while the top is not refuted.

The Guide covers domains the project defines itself ("the rules are the source") but not how to read hypotheses when the judge is the builder.
