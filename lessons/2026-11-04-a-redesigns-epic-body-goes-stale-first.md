While sessions redraw a design, the epic's body goes stale first, because it is rewritten only once they settle, yet it reads as the design's summary, so an agent grounding itself from it argues from concepts an earlier session already dropped. In one Adopter an agent proposed a home for a concept in two outputs the design on the working branch had removed, and only found out on checking its work. The Skill should have the agent ground itself in the docs on the session's working branch, and treat an epic body or an earlier session's handoff as history until they agree. An epic whose body is stale should say so in its first line.
