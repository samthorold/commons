A reading rule that rules by its instrument's error ("more than twice the standard error") should declare how that error is computed, above all the unit treated as independent, and the instrument should compute it before the first reading under the rule. Observations drawn from the same run (positions or choices within one game, events within one session) are correlated, so an error counted per observation overstates certainty and can turn noise into *supported* or *refuted*. In the origin, the rule named the error counted by game, but the instrument reported no error at all, so the agent reading the hypothesis had to add the by-game error mid-reading. That is an instrument change made at the moment it can bend the result. The detail file says when a rule is asymmetric because of its instrument's error, but not that the rule must name how the error is computed, or that the instrument must already implement it.
