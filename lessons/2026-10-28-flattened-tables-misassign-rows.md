A web-fetch tool that converts a page to text flattens its tables, and the model summarising the text can then assign a cell to the wrong row. A delegated researcher read a store's fee table as giving a 20% rate where the page gives 10% for the tier that applied, while a second read of the same page gave 10%; the researcher reported the disagreement without settling it. Settling it took asking the tool to quote the table cell by cell, in order, and reading the rows off that. Any figure taken from a table on a fetched page is worth that cell-by-cell check before it goes into a domain doc, and a researcher's brief can ask for table cells quoted in order rather than summarised.
