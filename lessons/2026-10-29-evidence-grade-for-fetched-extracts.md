The evidence notes the Stance asks for (read in full, abstract only, recalled) don't fit how a research agent mostly reads the web. A fetch tool returns an extract answering a question about the page, not the page itself. Grading that "full" overstates what was read, and "abstract" misdescribes it. A research agent independently added a grade, "extract": the page was fetched and the cited passages quoted, but it wasn't read line by line. The Stance should name a grade like this, so that research notes grade web sources consistently.
