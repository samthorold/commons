A recorded property's helper can check more than the property says. Here a property about what an act's output states searched each statement together with the names tied to it. A temporary bridge had tied every statement to every name the input mentions, so the helper was matching text the statement never held. While the bridge stood, the property held on output that might not have passed it on the statements alone. Removing the bridge narrowed the helper back with no re-record, and the samples happened to still pass, but nothing would have said so if they hadn't held before.

How it would apply: a property's helper reads only the output field the property is about. When a change removes a bridge or a derived field, check every property helper that reads it, as part of the change, since a replay stays green either way.
