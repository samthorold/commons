A hypothesis's setup can be a hand-authored scenario file (a world description checked into the repo), not only a mesocosm built in code or a search's output. An Adopter's Due triggers tend to name the mechanisms and instruments ("a change to the stepper makes every hypothesis Due"), and a data file changes without touching any of them, so an edit to the setup slips past the register. A general Convention: any file a hypothesis names as its setup is part of its mapping, and a change to it makes that hypothesis Due.
