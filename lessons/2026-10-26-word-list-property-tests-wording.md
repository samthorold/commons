A recorded property that is a list of words ("no output statement contains *will*, *would*, *set to*, *is to*") tests the act's wording, not its judgement, and fails both ways. The model meets it with synonyms when the instructions state the standard by meaning, and naming the list's words in the instructions to make it pass teaches the model to swap words. In the case, that produced a statement worded as though a planned thing already existed. The list also catches legitimate uses: "is set to be built" was the very wording of an arrangement that the standard counts as reportable, and a reported saying ("X said Y will…") was already acceptable.

How it would apply: assert a property on the cases the standard is about (named fixtures, each case asserted present in the input), and report word counts in the change's yield for the owner to read, rather than asserting them. Never put a property's own words into the act's instructions.
