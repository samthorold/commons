A noun the agent coins can reach the language file unagreed, because it travels inside a change the owner accepted for its concepts. The Skill says settled vocabulary goes in when the owner agrees the term, but nothing separates agreeing the concept from agreeing the word. In one Adopter an agent's coined noun merged as part of a broad direction, and the owner asked several exchanges later what it even meant, after it had been used against them repeatedly. Other coinages in the same session ("thread", a working name for a rule) drew the same objection. The agent should name each new noun as its own when offering it, ask for the word separately, and otherwise describe the thing in the terms already agreed.
