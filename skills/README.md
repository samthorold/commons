# Skills

Procedures, one `SKILL.md` directory each. A Skill applies the Guides rather than restating them. How they're linked into `~/.claude/skills/` is in the dotfiles README.

They form one delivery pipeline: `grill-me` / `grill-with-docs` → `to-prd` → `to-issues` → `triage` → `grind-issues` → `tdd`, with `diagnose` for hard bugs, `prototype` for throwaway answers to design questions, `handoff` between sessions, and `setup-matt-pocock-skills` to give a new repo the `docs/agents/` files the others read.
